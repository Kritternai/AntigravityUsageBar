# AntigravityUsageBar (App Bundle)

Native macOS menu bar application for tracking Google Antigravity model quotas, reset times, and local token usage.

Inspired by [Kritternai/ClaudeUsageBar](https://github.com/Kritternai/ClaudeUsageBar).

## Build

```bash
./build.sh
```

## Package DMG

```bash
./create_dmg.sh
```
