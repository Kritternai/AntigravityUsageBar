Features

Everything you need. Nothing you don't.

Zero setup

Finds the running Antigravity language_server on its own. No cookies or tokens to paste.

Every model

Gemini, Claude, and GPT-OSS quotas with live reset countdowns. Your active model is highlighted.

Token usage

Today and all-time input, output, and cache tokens — read from your local transcripts.

Gentle alerts

One shortcut

Private by design

Talks only to 127.0.0.1. No analytics, no servers, no accounts.

How it works

Three quiet steps, every minute.

01

Discover

Locates the local Antigravity server process, its port, and session token.

02

Ask

Requests your quota status over localhost — the same data Antigravity itself uses.

03

Show

Updates the menu bar with a color-coded percentage and a clean popover.

FAQ

Questions, answered.

Do I need to paste a cookie or API key?

No. While Antigravity is open, its local server already knows your quota. The app reads it over 127.0.0.1 automatically.

macOS says the app can't be opened.

The build is ad-hoc signed. Right-click the app and choose Open, or run xattr -cr /Applications/AntigravityUsageBar.app once.

Why does the menu bar show “--%”?

Antigravity isn't running, so there's nothing to read. Open Antigravity and the number appears within a minute.

Does any data leave my Mac?

Never. There are no external requests, analytics, or accounts. The code is open for you to check.
