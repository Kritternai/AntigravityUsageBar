// 01. ZERO-CONFIG PIPELINE

HOW IT READS QUOTAS WITHOUT COOKIES

100% LOCALHOST LOOPBACK · ZERO EXTERNAL REQUESTS
STEP 01 // PROCESS SCAN

Auto-Discover Daemon

Scans active macOS processes for Antigravity's background language_server and extracts the dynamic --csrf_token and listening TCP ports via lsof.

ps -ax | grep language_server --csrf_token
STEP 02 // LOCALHOST RPC

Query GetUserStatus

Executes a local Connect-RPC POST over 127.0.0.1 to fetch real-time remainingFraction, resetTime, and plan credit balances for every model.

POST /exa.language_server_pb.LanguageServerService/GetUserStatus
STEP 03 // TRANSCRIPT PARSER

Aggregate Token Logs

Parses local JSONL logs inside ~/.gemini/antigravity/brain to compute exact Today and All-Time input, output, and cache-read token counts.

~/.gemini/antigravity/brain/*/transcript.jsonl
